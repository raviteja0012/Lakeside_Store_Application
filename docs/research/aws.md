# AWS (ca-central-1 focus): feature surface

Researched 2026-08-12 against the vendor's live documentation, not from memory. 60 capabilities.

**This is a reference catalog, not a plan.** What we adopt and what we decline, with reasons,
lives in [CAPABILITIES.md](../CAPABILITIES.md). The services actually wired up today live in
[PLATFORM.md](../PLATFORM.md). Re-check anything here before acting on it: vendor pricing and
feature names move, and this is a dated snapshot.

Scope note from the researcher:

> Amazon Web Services (researched against docs.aws.amazon.com and the AWS Price List API, ca-central-1 offer files, August 2026). All ca-central-1 prices below were pulled from the machine-readable price list for Canada (Central) unless the entry says otherwise. Region availability was checked against the AWS General Reference endpoints tables, not from memory. Three findings dominate this research and are repeated in the relevant rows: (1) SES inbound email receiving IS now available in ca-central-1, which makes AWS a genuine candidate for the QUEUED "email invoice intake" requirement; (2) Amazon Bedrock in ca-central-1 offers Anthropic Claude only through Geo or Global cross-region inference profiles, never in-region, so a Bedrock migration would weaken, not strengthen, the Canadian-residency story the owner has been told in docs/owner-notes/store-app-infrastructure.html; (3) Amazon Rekognition in ca-central-1 supports face operations only, so DetectText, DetectLabels and moderation are unavailable in Canada.
